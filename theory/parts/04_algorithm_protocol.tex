\section{Algorithm derived from the theory}
The theoretical controller has four gates. At sparse checkpoints, estimate a stable target-weighted prediction/representation state on an independent probe.

\paragraph{Gate A: current value.}
For an ideal mode, use
\[
\widehat V_j(H)=\frac12\widehat a_j^2
\left(1-e^{-2\widehat\mu_jH}\right).
\]
For a structural candidate (e.g. neuron subset), directly measure the change in frozen-readout probe risk and target accessibility.

\paragraph{Gate B: persistence / future discovery.}
Do not delete while the relevant subspace is moving rapidly or while it is statistically unresolved. Use cluster projectors, eigengaps, principal-angle speed, and repeated checkpoints. A conservative theoretical envelope is supplied by Theorem~\ref{thm:persistence}; an empirical proxy may use recent Grassmannian motion.

\paragraph{Gate C: structural realizability.}
Require a small structural approximation term $\delta$ in Theorem~\ref{thm:structural-transfer}. For the final hidden layer this can be implemented by rank-revealing neuron subset selection.

\paragraph{Gate D: compute value.}
Delete only if the upper bound on retained finite-horizon value is below the measured compute saved. All diagnostic overhead must be charged.

\begin{center}
\fbox{\parbox{0.92\linewidth}{
\textbf{Provisional Spectral Rank Annealing (SRA).}
Train the dense network normally during the discovery phase. At sparse checkpoints, estimate stable target-weighted spectral clusters and their finite-horizon value. Once a low-value cluster is both resolved and persistent, map it to the smallest structural contraction whose current probe distortion is below tolerance. Contract the architecture, rebuild only the affected optimizer state, and continue the same base optimizer. Repeat only after a new persistence window. If no representation block has positive value-per-compute, freeze the backbone and solve the readout.
}}
\end{center}

The first implementation in this repository intentionally contracts only the final hidden layer. This is the cleanest place where a coordinate-level neuron deletion produces a genuine parameter/FLOP reduction and where the representation/prediction spectrum has an exact linear-readout interpretation. Extension to internal nonlinear layers requires an explicit structural-transfer bound rather than an analogy.

\section{Empirical protocol and falsification criteria}
The decisive comparison is not against a weak pruning baseline. It is
\[
\text{same initialization + same data order + same base optimizer}
\]
for a dense model and the contraction controller. The primary plots are test metric versus total measured compute and active parameters versus training time. Every SVD, probe forward pass, Jacobian call, checkpoint, and model-rebuild cost is charged to the proposed method.

The minimum empirical ladder is:
\begin{enumerate}
\item \textbf{Exact fixed-geometry audit.} Numerically verify Theorem~\ref{thm:fixed-value} to machine precision.
\item \textbf{Solvable quadratic teacher--student.} Verify that pruning before the last BBP crossing destroys a teacher mode while post-separation spectral truncation preserves the resolved target sector.
\item \textbf{Small real MLPs.} Digits and breast cancer, with disjoint train/probe/test splits. Compare dense AdamW with final-hidden-layer contraction, including an optimizer-reset dense control.
\item \textbf{Image scale.} ResNet/CIFAR and then ImageNet. Contract channels, not unstructured weights, so FLOP savings are real.
\item \textbf{Transformer scale.} Fine-tuning and continued pretraining. Candidate structural units are MLP intermediate rank, attention heads, or low-rank factors. Compare with strong dynamic sparse/rank baselines.
\end{enumerate}

A result is considered negative if any of the following holds after matched compute: the controller does not reduce wall-clock/FLOPs, test performance falls outside a predeclared tolerance, probe overhead consumes the saved compute, or the onset rule fails to transfer across configurations.

\section{Position relative to existing methods}
The novelty cannot be ``pruning during training'' or ``adaptive rank.'' Dynamic Sparse Training, RigL/SRigL, Early-Bird tickets, EigenDamage, spectral pruning, AdaLoRA, GaLore, and recent dynamic-rank training already occupy those spaces. The distinctive scientific claim pursued here is narrower:
\begin{quote}
A target-weighted prediction-space theory determines the finite-horizon value of capacity, proves why deletion must wait for feature-discovery/separation, and supplies an explicit error budget for turning that spectral decision into structural contraction.
\end{quote}
The strongest version of the paper would therefore combine (a) exact finite-horizon mode value, (b) an onset theorem, (c) a structural transfer theorem, and (d) matched-compute evidence that the resulting contraction rule beats dense training and strong compression baselines without using test information.

\section{What remains mathematically hard}
Three problems separate this draft from a definitive theory. First, a cheap observable upper bound on future $\norm{\dot L_t}$ and cluster motion is architecture-dependent; the universal theory can only expose the interface. Second, converting a prediction-space cluster into a hardware-friendly internal-layer contraction without large structural gap $\delta$ requires architecture-specific results. Third, repeated adaptive probing alters future training after the first contraction, so finite-sample guarantees need fresh probes, cross-fitting, stability, or martingale control rather than the simpler stopping-time argument available to pure early stopping.

These are not reasons to avoid the algorithm. They are the exact places where the theory says empirical shortcuts must be labeled as proxies rather than certificates.
