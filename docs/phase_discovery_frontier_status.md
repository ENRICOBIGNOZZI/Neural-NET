# Dynamic-BBP discovery frontier status

Protocol frozen before the first run. The experiment tests a theory-predicted width-sensitive discovery mechanism rather than tuning the controller after the negative rank-factor MLP result.

Primary quantities are same-time discovery advantage `D`, declared-cost equal-compute margin `D-O`, target overlap of the target-free selected top mode, and the critical wide-to-compact cost ratio `rho_star`. The asymptotic BBP time, checkpoints, 50 seeds, compact horizon, and cost-ratio grid are fixed in `experiments/PHASE_DISCOVERY_FRONTIER_PROTOCOL.md`.

No hardware claim is attached to the random-matrix column count. The experiment reports the entire cost frontier so that a later structurally contractible neural architecture can be located on it using measured cost.
